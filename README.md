# C# & LINQ Practice Problems

This repository contains C# console applications covering fundamental concepts, LINQ queries, collections, and string handling.

## 🚀 Projects Included

1. **Employee LINQ Queries**
   - Filtering, grouping (department-wise avg salary), sorting, and projections.
2. **Phonebook Console App**
   - CRUD operations using `Dictionary<string, string>` and LINQ sorting.
3. **Array Duplicate Handler**
   - Finding and removing duplicates via manual nested loops vs. LINQ (`Distinct`, `GroupBy`).
4. **String Manipulation Suite**
   - Custom string reverse, vowel counting, anagram validator, and word frequency counter.
5. **Student Management System**
   - Complete console app featuring class toppers, subject averages, and grade distributions.

## 🛠️ Built With
- C# / .NET
- LINQ (Language Integrated Query)
